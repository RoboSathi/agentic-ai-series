# Refunds

## Which orders can be refunded
Only a delivered or a cancelled order can be refunded. A delivered order can be refunded because the customer has it and wants their money back. A cancelled order can be refunded when its refund has not been paid yet, because the customer never received it. Cancelling through support pays the refund in the same step, so an order cancelled that way already shows an issued refund and is not refunded again.

While an order is pending or shipped it is still on its way, and there is nothing to refund yet. A pending order can be cancelled instead. A shipped order can be refunded once it is delivered.

## One refund per order
Each order can be refunded once. When an order already shows an issued or completed refund, it cannot be refunded again. The agent should say so plainly rather than open a second request.

## Full refunds only
A refund is always for the full order total. Partial refunds are not supported, whether the agent issues the refund or a human reviewer approves it.

## Human review
Most refunds are issued as soon as the order is confirmed as eligible. Some are checked by a person before any money moves. Those are placed in the review queue, and the customer is told their refund needs a manual review and that they will hear back soon.

A reviewer can approve or deny a queued refund. An approved refund is then issued exactly like an automatic one.

## Cancelling an order
An order that has not shipped yet can be cancelled. Cancelling refunds the full order total in the same step, and like a refund it may be checked by a person first. Once an order has shipped it can no longer be cancelled; it can be refunded after it is delivered.

## Issued, then settled
A refund is issued first and settles a few minutes later, the way a card payment does. Until it settles, a member of staff can void it: the payment is reversed and the order shows no refund again. Once it has settled it can no longer be voided, and the customer receives a confirmation message.

## When the money arrives
Once a refund has settled, it goes back to the original payment method. Card refunds usually show on the statement within 5 to 10 business days, depending on the customer's bank.

## What if a refund fails part-way
Issuing a refund updates the order and records the payment; the customer is notified when it settles. If any step fails, the steps already taken are undone, so an order is never marked as refunded without the money being recorded, or the reverse. The customer can simply ask again. Asking twice for the same refund never pays twice.
