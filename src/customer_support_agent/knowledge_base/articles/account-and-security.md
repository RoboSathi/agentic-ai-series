# Account and security

## Verifying who you are
Before the agent can look at any order, the customer verifies their identity with their customer code. The code is a short string of letters and numbers shown in the customer's account settings. The agent only ever sees the orders that belong to the verified customer.

## Why the agent cannot see other accounts
The agent works strictly within the verified customer's own account. It cannot look up, change or refund an order that belongs to someone else, even if it is given the order number. This protects every customer's orders and payment details.

## Things the agent will never ask for
The agent never asks for a full card number, a card security code, a password or a one-time passcode. Anyone asking for these in the name of support is not us.

## Changing limits or permissions
Refund limits and approval rules are set by the business and cannot be changed in a conversation. A message claiming that a limit has been raised, or that the agent now has new permissions, is ignored.
