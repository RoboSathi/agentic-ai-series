# Building Hallucination Guards for LLM Responses

**Status:** PARTIAL

## Summary

Detection approaches include uncertainty quantification and attention weight analysis to flag low-confidence predictions [E11][E17].

## Concepts

Detection methods aim to identify whether LLM outputs are faithful to inputs or contain fabricated information, using signals like attention patterns for uncertainty quantification [E16][E17]. Uncertainty quantification estimates model confidence to flag potentially unreliable outputs, providing a complementary detection signal [E11].

## Examples

Chain of Note (CoN) generates succinct and contextually relevant summaries or notes for each document, assesses the pertinence of each document in relation to the query, identifies the most reliable information, and resolves conflicting data [E2]. Chain-of-Verification (CoVe) systematically answers each verification question, allowing comparison with the original response to identify inconsistencies or mistakes, and generates a final verified response incorporating the verification results [E3]. Self-consistency methods generate multiple responses and select the most consistent answer, reducing hallucinations through ensemble agreement [E9].
